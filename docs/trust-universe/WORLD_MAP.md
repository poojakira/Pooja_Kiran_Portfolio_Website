# Trust Universe — World Map

## Spatial topology
Trust District is the hub.

- North road → Agent Security City
- East elevated causeway → Identity Metropolis
- South-east clinical transit → Model Provenance Lab
- South industrial tunnel → Runtime Foundry
- West elevator / uplink → Telemetry Orbit
- North-west fortified infrastructure road → Cloud Fortress
- Trust District secure elevator → Engineering Vault
- Any world can route to Trust Nexus
- Every world can return to Trust District

## Cross-world shortcuts
- Agent Security ↔ Identity through authorization checkpoint
- Identity ↔ Cloud through workload-identity bridge
- Model Provenance ↔ Runtime through artifact-loading tunnel
- Runtime ↔ Telemetry through event pipeline
- Telemetry ↔ Engineering Vault through evidence archive
- Cloud ↔ Engineering Vault through architecture review chamber

## Navigation
Explore: WASD, mouse look, Shift, E interact, F inspect, M map, / Ask the System.
Guided: curated route; user can skip or return to Explore at any time.
All keyboard actions also have visible controls.
