# Trust Universe — Story, Interaction, Vehicle, Camera and Briefing Systems

## Story system
Each domain answers four things:
1. security problem;
2. control boundary;
3. what Pooja actually built;
4. evidence + limitations.

## Interaction system
- EXPLORE: free movement and discovery.
- GUIDED: cinematic authored route.
- RECRUITER: premium editorial fast path.
- ENGINEERING: evidence-first technical interface.
- QUICK ACCESS is always available.
- First-entry world briefing plays once per session and can be replayed.

## Vehicle gray-box
Original ultra-luxury autonomous EV; no commercial branding.
- E / click to enter or exit.
- Drive: intentionally slow, heavy and forgiving.
- Autopilot: select destination from world map.
- Travel hides world streaming.
- Collision response is corrective rather than punitive.

## Camera
Explore: human eye-level, 35–50mm equivalent, damped movement, minimal bob.
Vehicle: interior / exterior chase / autopilot choreography.
Inspect: 85mm+ feeling, slow object focus.
Guided: 24–50mm authored compositions; always skippable.

## Briefings
First-entry briefing contains only:
WORLD, thesis, problem, Pooja built, why it matters, 3–4 actions.
Environment motion/audio should de-emphasize during briefing.
