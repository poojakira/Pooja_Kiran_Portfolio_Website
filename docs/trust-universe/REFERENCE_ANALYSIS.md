# Trust Universe — Reference Analysis

## Purpose
Use the two user-selected references as interaction/art-direction studies, not as assets to copy.

## Reference 1 — Interactive 3D scrolling
Principles to retain:
- Camera movement has weight; it should not map 1:1 to wheel delta.
- Scroll can choreograph camera, object scale, reveal timing and depth.
- A focal 3D object should dominate a composition before supporting text appears.
- Scene changes should be motivated by camera movement, not by page-section swaps.
- Motion hierarchy: environment first, focal system second, typography third.
- Cinematic moments must have anticipation, hold and release.

## Reference 2 — “Aura”
The user’s intended design reading is atmosphere rather than an effect pack:
- strong still-frame composition;
- restrained typography;
- lighting, depth and material quality carry the mood;
- fewer UI surfaces, stronger spatial relationships;
- transitions feel authored rather than generic;
- visual identity should survive when animation is paused.

## Combined rule
Scroll cinematics are used only in Guided mode and transitions. Explore mode remains spatial and non-linear.

## What we will not copy
No Marvel/Iron Man assets, UI, suit motifs or branded HUD language. No direct recreation of either reference site.

## Production test
Every hero view must work as a screenshot before motion is added. Animation is not allowed to rescue weak composition.
