# Pooja 3D Avatar Contract

Place the identity-accurate, rigged avatar here as:

`public/models/pooja-avatar.glb`

## Required characteristics

- Full human body: head, torso, arms, hands, legs, feet.
- Realistic proportions and materials. Avoid cartoon, anime, or low-poly styling.
- Preserve Pooja Kiran's recognizable facial identity from approved reference images.
- Professional dark security-engineering clothing appropriate to the facility scene.
- Forward axis should face toward negative Z in the exported scene where possible.
- Origin at floor level between the feet.
- Real-world scale close to 1.62 m / 5 ft 4 in before any scene scaling.
- Keep textures web-optimized and embedded or stored beside the GLB.
- Prefer a compressed web asset with Draco/Meshopt where practical.

## Rig / animation expectations

Preferred animation clip names:

- `Idle`
- `Walk`
- `TurnLeft`
- `TurnRight`

Optional:

- `LookLeft`
- `LookRight`
- `Gesture`

The current portfolio scene already provides the third-person path, camera follow, doors,
guide robot, stage transitions, recruiter hooks, voice guide, and environmental lighting.
The committed procedural humanoid is a temporary full-body fallback only and is not presented
as an identity-accurate likeness.
