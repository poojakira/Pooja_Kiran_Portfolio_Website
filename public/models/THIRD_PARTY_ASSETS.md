# Third-Party 3D Assets

## Trust Grand Tourer baseline

Source: KhronosGroup glTF Sample Assets — CarConcept  
Source URL: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CarConcept  
License: Creative Commons Attribution 4.0 International (CC BY 4.0).

The portfolio derivative removes/replaces brand/logo/license materials, uses a dark graphite paint treatment, and downscales textures for real-time web delivery. The source model documentation describes PBR car paint, glass/interior materials, ambient occlusion, clearcoat and real-time optimization.

## Realistic female guide baseline

Source: Microsoft Rocketbox Avatar Library — Female_Adult_01  
Source URL: https://github.com/microsoft/Microsoft-Rocketbox  
License: MIT.

The web derivative uses the Rocketbox adult female mesh/rig, selected body/head/hair texture maps, and the Rocketbox female idle breathing animation. Textures are downscaled for web delivery.

**Important:** this generic Rocketbox character is a realism baseline only. It is not presented as a likeness of Pooja Kiran.
